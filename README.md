# Капри для iPhone

Отдельное приложение: только чат с Капри, её голос, память и уведомления «заскучала».
Никакого управления компьютером — это личная болталка с характером.

## Что умеет

- **Чат с характером** — тот же голос, флирт, подколы и мат, что у настольной Капри.
- **Озвучка** — русский системный голос с поднятым тоном, свой тембр вместо «робота». Можно выключить.
- **Голосовой ввод** — кнопка микрофона, распознавание русской речи на телефоне.
- **Память** — запоминает имя и факты из фраз «меня зовут Ярослав», «я люблю пиццу», помнит переписку.
- **Уведомления** — 2–5 раз в день в случайное время с 10:00 до 23:00: скучает, зовёт, флиртует.
  Нажал на уведомление — Капри пишет в чат первой. Всё локально, без сервера.

## Что нужно

- iPhone (iOS 17 и новее).
- GitHub-аккаунт — там соберётся `.ipa` на macOS-раннере, бесплатно.
- [Sideloadly](https://sideloadly.io) на Windows для установки.
- Платный Apple Developer ($99/год) — подпись живёт год, а не 7 дней.
- Ключ Gemini — тот же, что у настольной Капри (`api_key` в `config.json`).
- VPN на iPhone: Google не пускает Gemini с российских адресов, приложение честно об этом скажет.

## Сборка IPA через GitHub Actions

1. Создай **приватный** репозиторий на GitHub, например `capri-ios`.
2. Залей туда содержимое папки `ios` (это корень репозитория):

   ```bash
   cd ios
   git init
   git add .
   git commit -m "Capri iOS"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/capri-ios.git
   git push -u origin main
   ```

3. Открой в репозитории вкладку **Actions → Build IPA → Run workflow**
   (или просто дождись автозапуска после пуша). Сборка идёт ~4–6 минут.
4. В завершённом запуске скачай артефакт **Capri-ipa** — внутри `Capri.ipa`.

Ключ API в репозиторий не попадает: его вводишь на телефоне при первом запуске.

## Установка на iPhone

1. Подключи iPhone кабелем, открой Sideloadly.
2. Перетащи `Capri.ipa` в окно Sideloadly.
3. Введи свой Apple ID (платный аккаунт), нажми **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством → Доверять разработчику**.
5. Если iOS ругается на непроверенное приложение — разреши в настройках, как обычно при сайдлоаде.

Подпись платным аккаунтом действует год, переустанавливать раз в неделю не нужно.

## Первый запуск

1. Вставь ключ Gemini (поле «Ключ API»), сохрани.
2. Разреши уведомления, микрофон и распознавание речи.
3. Включи VPN, если Капри отвечает «Google меня не пускает из этой сети».
4. Для лучшего голоса: **Настройки iOS → Универсальный доступ → Контент для озвучивания →
   Голоса → Русский** и скачай улучшенный голос. Приложение само выберет premium/enhanced.

## Как работают «скучаю»

При каждом открытии приложения (и уходе в фон) Капри перемешивает расписание на три дня вперёд:
случайные часы с 10 до 23, количество зависит от частоты в настройках. Когда приходит уведомление
и ты его открываешь, в чате появляется её сообщение.

Это локальные уведомления iOS — сервер и пуш-сертификаты не нужны, работают без интернета.

## Настройки в приложении

- **Нейросеть** — ключ, адрес API, модель (по умолчанию `gemini-3.5-flash-lite`).
- **Голос** — вкл/выкл озвучки, высота тона, кнопка «Послушать голос».
- **Уведомления** — вкл/выкл, как часто, проверка через 8 секунд.
- **Память** — имя, факты, «Забыть всё».

## Сборка на Mac (если есть)

```bash
brew install xcodegen
xcodegen generate
open Capri.xcodeproj
```

Дальше выбери свою команду в Signing & Capabilities и запускай на телефоне.
Bundle ID по умолчанию `com.yaroslav.capri` — меняется в `project.yml`.

## Ограничения

- Без VPN Gemini отвечает ошибкой региона — это ограничение Google, а не приложения.
- Качество голоса зависит от системного русского голоса; улучшенный голос надо скачать в iOS.
- Микрофон и распознавание речи работают через системные разрешения iOS.
- Приложение не управляет компьютером: это отдельная болталка, а не пульт для ПК.
